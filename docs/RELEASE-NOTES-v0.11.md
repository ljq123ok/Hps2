# HPS2 v0.11

HPS2 是基于 ARMSX2 / PCSX2 的 HarmonyOS、OpenHarmony PS2 模拟器移植项目。
本仓库及发布包不包含 BIOS、游戏镜像或签名材料。

## 新增功能

- 即时存档：8 个槽位，支持保存、读取和删除
- 可拖动 FPS 悬浮球与展开式快捷操作
- 基于 ArkUI 标准按键/摇杆事件的蓝牙手柄输入
- 日间、夜间主题
- 错误分类、BIOS 基本规格检查和诊断日志导出
- 选择 BIOS 或游戏后的加载提示

## 主要修复

- 大型游戏镜像复制不再阻塞界面
- 修复游玩页切换、旋转黑屏、全屏系统栏和返回停止问题
- 修复虚拟按键尺寸、定位和悬浮控件对比度
- 即时存档操作统一切到 VM 线程，失败后会恢复原运行状态

完整变更和已知限制见 [CHANGELOG-2026-09-22.md](CHANGELOG-2026-09-22.md)。

## 安装说明

- 发布附件为未签名 Debug HAP，需要使用自己的开发者账号和调试证书签名。
- 当前 JIT 依赖调试签名环境；release/normal 签名下不可用。
- BIOS 与游戏镜像请由用户自行从合法拥有的设备或介质获取。

## 已知限制

- 蓝牙手柄代码已完成，但不同型号仍需更多真机验证。
- Vulkan 后端、多核优化和应用市场版的非 JIT 降级路径尚未完成。
