# Hps2 v0.16 自签 JIT 测试版

- 应用版本：`0.16`（`versionCode` `1000016`）
- 包名：`com.hps2.jitprobe`
- 发布包：arm64 未签名 debug HAP；安装前需使用自己的开发者证书签名。
- 本次测试设备：HUAWEI Pura X View。

## 更新与修复

- 重构首页和主要前端页面，统一视觉层级、状态卡片、导航与布局。
- 优化折叠屏内外屏切换及横竖屏使用体验。
- 修复启动重入导致全局路径过早释放的问题。
- 修复存档失败后模拟器运行状态未恢复，以及扳机抬起值错误。
- 修复虚拟按键编辑拖动与游戏内位置不一致、画面尺寸更新未及时应用、透明度未实时刷新的问题。
- 增强原生层崩溃防护，处理 UI 阻塞与资源引用泄漏。
- 调整 JIT 看门狗复用 PERF 采样节拍，减少重复采样。
- 增加游戏库多镜像管理、封面来源设置和逐游戏画面比例、倍率、MTVU 覆盖选项。

## 隐私与签名

- 本 HAP 为未签名的 debug 包，下载者必须用自己的签名证书与 Profile 签名后安装。
- HAP 不包含签名证书、私钥、Profile、BIOS、游戏镜像、用户存档、设备序列号或原始真机日志。
- JIT 能力由运行时探针检测；实际结果取决于设备、系统版本和签名配置。

## 验证边界

- Pura X View 测试录屏展示了首页、设置页、横屏游戏画面和虚拟按键。
- 本发布记录不把录屏视作覆盖所有功能的完整回归测试，也不据此声称所有设备均已验证。
