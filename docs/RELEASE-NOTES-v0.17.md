# Hps2 v0.17 扫描游戏修复版

- 应用版本：`0.17`（`versionCode` `1000017`）
- 包名：`com.hps2.jitprobe`
- 发布包：arm64 未签名 debug HAP；安装前需使用自己的开发者证书签名。
- 本次测试设备：HUAWEI Pura X View。

## 扫描游戏修复

- 扫描 Download / Documents 目录及其子目录中的镜像，并申请对应的用户权限。
- 通过 native 内容探测识别 PS2 镜像，过滤 PS3 镜像、损坏文件和无法识别的候选项。
- 修复外部游戏路径 URI 与 native POSIX 路径不一致的问题。
- 修复外部游戏重启后丢失的问题；失效路径会从持久化清单清理。
- 启动前检查 native 是否能直接打开外部路径；不允许原地读取时回退复制到应用目录，并在界面明确提示。
- 支持扫描结果批量探测、按文件大小排序，以及只从列表移除外部游戏而不删除用户文件。

## 隐私与签名

- 本 HAP 为未签名的 debug 包，下载者必须用自己的签名证书与 Profile 签名后安装。
- HAP 不包含签名证书、私钥、Profile、BIOS、游戏镜像、用户存档、设备序列号或原始真机日志。
- JIT 能力由运行时探针检测；实际结果取决于设备、系统版本和签名配置。

## 验证边界

- 本版完成本地源码检查和 debug HAP 构建验证。
- 真机权限弹窗、公开目录访问、原地读取与回退复制仍需在目标设备上逐项验证。
