# Hps2 v0.14 P1/P2 测试版

- 应用版本：`0.14`（`versionCode` `1000014`）
- 包名：`com.hps2.jitprobe`
- 发布包：arm64 未签名 debug HAP；安装前需要使用自己的签名配置。

## 更新

- 增加启动时 JIT 运行能力探针及诊断信息，便于区分系统调用结果与实际代码执行结果。
- 游戏信息页显示识别到的游戏序列号、标题和 CRC。
- 诊断日志不再写入文件选择器 URI、用户文件路径等动态路径信息。
- 更新源码恢复和依赖锁定构建脚本，方便在新工作区复现构建。

## 验证状态

- 本地 Hvigor `assembleHap` 构建成功，发布 HAP 通过 ZIP 完整性及静态隐私标记检查。
- 本版 HAP 尚未完成真机安装、游戏运行及长时间稳定性回归。此前设备上的探针结果只适用于当时的具体构建和环境，不代表 JITFort 支持或所有签名配置均可用。
- OpenGL 为现有图形路径；Vulkan 后端和性能基准仍未完成。
