# Hps2 v0.13

**版本**：0.13（`versionCode` 1000013）

## 本次新增

- 原生 HarmonyOS GameControllerKit 手柄桥接：枚举外接手柄、选择端口 0，并把按键、十字键、双摇杆和 L2/R2 轴映射到 PS2 手柄输入。
- 游戏内暂停/继续：通过 native VM 状态切换实现真实暂停，悬浮球会显示当前状态。
- 原生手柄接管时禁用 ArkUI 手柄焦点接收，避免十字键同时导航悬浮菜单。
- 保留 SDL/虚拟手柄回退路径；API 不支持 GameControllerKit 的设备仍可使用原有输入路径。

## 本次修复

- 修复外接手柄被 ArkUI 焦点抢占导致按键误触悬浮 UI 的问题。
- 修复暂停状态未上报前端、暂停按钮状态与 VM 状态不一致的问题。
- 补齐 L3/R3 映射，并统一原生 GameControllerKit 轴值到 SDL 轴范围。

## 测试记录

- 手柄：盖世小鸡 X5S 拉伸蓝牙手柄。
- 构建：HarmonyOS HAP 非增量构建通过；ArkTS 仅有既有弃用/API 能力提示，无编译错误。
- HAP 检查：未发现 BIOS、游戏镜像、签名材料、设备序列号或原始诊断日志。

## 隐私与发布边界

- GitHub 只发布源码和文档，不提交 `.hap/.hsp`、证书、私钥、签名 profile、BIOS、游戏镜像、存档、原始日志或设备标识。
- HAP 需在本地使用开发者自己的签名材料生成；签名材料不会写入仓库。
