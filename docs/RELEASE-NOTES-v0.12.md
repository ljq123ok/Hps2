# HPS2 v0.12

HPS2 是基于 ARMSX2 / PCSX2 的 HarmonyOS、OpenHarmony PS2 模拟器移植项目。
本仓库及发布包不包含 BIOS、游戏镜像或签名材料。

## 新增功能

1. **即时存档**
   - 提供 8 个存档槽位，支持保存、读取和删除。
   - 保存和读取通过 VM 线程任务队列执行；删除时同时处理 `.backup` 文件。
   - 旧构建创建的即时存档可能不兼容，遇到异常时请删除旧档并重新保存。
2. **可拖动 FPS 悬浮球**
   - 直接显示实时 FPS，可拖动并停留在最终位置。
   - 展开后提供运行状态、存档、虚拟按键显隐、设置、返回和收起操作。
3. **蓝牙手柄输入**
   - 使用 HarmonyOS 标准按键和摇杆事件，统一映射 Xbox、PlayStation、Switch 的物理按键位置。
   - 检测到手柄输入后可自动隐藏屏幕虚拟按键。
4. **日间与夜间主题**
   - 使用 HarmonyOS 资源限定符提供两套语义颜色。
   - 游戏画面上的虚拟按键和悬浮控件继续使用固定高对比度配色。
5. **错误诊断工具**
   - 对 JIT、BIOS、内存和渲染表面等错误分类并给出处理建议。
   - 选择 BIOS 后检查常见文件大小和签名字符串。
   - 可导出设备型号、系统版本、JIT 状态、启动阶段、错误信息和核心日志尾部。
6. **加载提示**
   - 选择 BIOS 或游戏后显示文件名和加载动画，完成后自动消失。
   - 加载期间拦截重复触摸，避免并发选择覆盖目标文件。

## 修复的问题

1. **大型游戏镜像复制导致界面卡死**：同步文件复制改为异步流程，并保留文件选择器授权 URI。
2. **选择游戏后无法进入游玩画面**：让 XComponent 始终挂载，首页改为覆盖层，消除表面初始化竞态。
3. **虚拟按键尺寸和位置异常**：修复固定尺寸被压缩、ArkTS getter 返回异常以及未按实际 4:3 画面定位的问题。
4. **旋转设备后黑屏**：方向变化时重建 EGLSurface 并重新绑定上下文。
5. **全屏时系统导航条未隐藏**：同时启用全屏布局并关闭系统栏。
6. **点击返回后应用无响应**：停止 VM 前先请求暂停，避免线程阻塞在执行循环导致 `join()` 等待。
7. **启动时偶发闪退**：移除在组件属性尚未初始化时执行的错误诊断格式化代码。
8. **悬浮条在浅色主题下看不清**：游戏画面覆盖控件改为固定高对比度颜色。
9. **即时存档读取后卡死或失败后停住**：
   - 存读档统一路由到 VM 线程，并等待执行循环到达安全点。
   - 超时且尚未开始的任务会被撤销；已经开始的任务会等待安全完成，避免迟到执行。
   - 读取失败后恢复操作前的运行状态，不再永久停留在暂停状态。

完整技术记录见 [CHANGELOG-2026-09-22.md](CHANGELOG-2026-09-22.md)。

## 安装说明

- 发布附件为未签名 Debug HAP，需要使用自己的开发者账号和调试证书签名。
- 当前 JIT 依赖调试签名环境；release/normal 签名下不可用。
- BIOS 与游戏镜像请由用户自行从合法拥有的设备或介质获取。

## 已知限制

- 蓝牙手柄代码已完成，但不同品牌和型号仍需更多真机验证。
- Vulkan 后端、多核优化和应用市场版的非 JIT 降级路径尚未完成。
- 最终签名安装、存读档与手柄兼容性由用户继续进行真机验证。
