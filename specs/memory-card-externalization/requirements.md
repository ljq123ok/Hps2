# PS2 记忆卡外置与跨模拟器读写

## 范围

本阶段只处理 PS2 记忆卡文件，不处理 Hps2 即时存档（`.p2s`）。运行中的核心继续使用应用沙箱中的 `memcards/` 目录；工程已配置 HarmonyOS `shareFiles`，但当前本机 API 24 工具链只能可靠提供系统文件选择器导入/导出，API 26 目录捐献待升级工具链后启用。

## 用户故事

- 用户可以查看 Hps2 当前可用的 PS2 记忆卡。
- 用户可以导入其他模拟器的记忆卡，并在 Hps2 中使用。
- 用户可以导出、复制、移动、改名和删除 `.ps2` 记忆卡文件。
- 用户可以把导出的标准记忆卡文件交给系统文件管理器，自行复制、移动、改名或删除；重新使用时通过导入回到 Hps2。

## 验收条件

1. 当应用创建或导入有效的 PS2 记忆卡时，系统应将其存放在 `memcards/`，并在列表中显示文件名、容量和格式。
2. 当用户通过系统文件选择器导入 `.ps2` 文件后，应用重新进入或刷新列表时，应能发现该文件；无效文件不得加入可用列表。API 26 共享目录启用后，再增加“文件管理器直接放入目录”的同目录发现路径。
3. 当用户导出记忆卡时，系统应生成原始可移植的 `.ps2` 文件，而不是 Hps2 专用容器。
4. 当记忆卡正在被虚拟机使用时，系统不得直接覆盖、改名或删除该文件。
5. 当用户删除记忆卡时，系统必须二次确认，并在删除前检查它未被任何槽位使用。
6. 当应用重新启动时，`memcards/` 中由文件管理器放入的文件仍应可见。
7. 系统不得把 `.p2s` 即时存档显示为本阶段可导入、导出或同步的数据。

## 非目标

- 不实现即时存档跨模拟器转换。
- 不把游戏镜像、BIOS 或其他运行目录共享给文件管理器。
- 不在虚拟机运行期间直接从外部文件管理器修改正在打开的记忆卡。
